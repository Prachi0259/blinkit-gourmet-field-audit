# Blinkit Gourmet Field Audit — DLF Phase 1, Gurugram

A hands-on assortment check of the Blinkit Gourmet category in one specific delivery zone, done the way a shopper would do it: open the app, set the zone, search brand by brand.

**Live page:** https://prachi0259.github.io/blinkit-gourmet-field-audit/

## What this is

I searched Blinkit for three gourmet brands with real demand in this micro-market. All three returned "Oops! We couldn't find products matching" — a zero-result search, not an out-of-stock badge. That distinction is the whole point: an out-of-stock item has a SKU and shows up in replenishment reports. A zero-result search means the brand was never onboarded to the zone, and it is invisible to every dashboard.

## The three brands

| Brand | Category | Search result |
|---|---|---|
| Cohoma | Indian specialty coffee | Zero results |
| Percol | Fairtrade certified UK coffee | Zero results |
| Cacao Springs | Craft single-origin chocolate | Zero results |

Screenshots of each search, taken live from the app with the delivery zone set to DLF Phase 1, are in the `proof/` folder.

## Method

- Delivery address set to DLF Phase 1, Gurugram
- Brand names searched one by one in the Blinkit app, same afternoon
- Each zero-result screen screenshotted as evidence
- Claims kept zone-level throughout; nothing here asserts what Blinkit carries nationally
